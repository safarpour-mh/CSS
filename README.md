# Fuzzy Equivalence–Driven Feature Selection with Constrained Sigmoid Similarity

This repository contains the MATLAB implementation of the feature selection framework proposed in our paper:

> **Fuzzy Equivalence–Driven Feature Selection with Constrained Sigmoid Similarity for Interpretable Supervised Learning**

The code includes the core methodology, experimental results generation, and the script used to produce Table 4 from the manuscript. The framework is designed to be label-agnostic during similarity computation, theoretically sound via fuzzy equivalence relations, and effective in achieving high sparsity while improving classification accuracy.
